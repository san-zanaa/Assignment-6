# FITLOG 🏋️

FITLOG is a modern workout management web application that helps users
discover exercises, view workout details, create a daily workout plan,
and save workouts for later.



### 📌 Project Description

FITLOG is a modern workout management web application. Users can browse available exercises, check workout details such as duration, calories, difficulty, equipment, sets, and reps, and add exercises to their 
daily workout plan or save them for later.


## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API
- Next.js App Router
- REST API
- Lucide React
- JavaScript (ES6)
- DaisyUI

### ✨ Features

- Explore a collection of different exercises and workouts.
- View detailed information including equipment, difficulty, sets, reps, duration, calories, rating, and instruction
- Add workouts to a personal daily workout plan and manage them easily.
- Mark workouts as completed and view total exercises, duration, and calories.
- Sort workouts by duration, calories, or rating
- Remove workouts from Today's Plan or Saved list
- Responsive design for different screen sizes
